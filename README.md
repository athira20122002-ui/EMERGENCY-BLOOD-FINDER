# 🩸 Blood Bank Finder

A simple Flask web application that helps users quickly find blood banks in their city. Enter a city name and get the blood bank's name, address, phone number, and available blood groups, backed by a lightweight SQLite database.

---

## ✨ Features

- 🔍 **City search**: look up blood banks by city name
- 🔤 **Case-insensitive, partial matching**: searching `poll` still finds `Pollachi`
- 📞 **Key details at a glance**: name, address, phone number, and available blood groups
- 🗄️ **SQLite database**: no server setup needed
- ⚡ **Lightweight**: just Flask and Python's built-in `sqlite3`

## 🚀 Getting Started

### Prerequisites

- Python 3.8 or higher
- pip

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/athira20122002/bloodbank-finder.git
   cd bloodbank-finder
   ```

2. **(Optional) Create a virtual environment**
   ```bash
   python -m venv venv
   source venv/bin/activate      # On Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install flask
   ```

4. **Create the database**
   ```bash
   python create_db.py
   ```
   You should see: `Database created successfully!`

5. **Run the app**
   ```bash
   python app.py
   ```

6. **Open in your browser**
   ```
   http://127.0.0.1:5000/
   ```

## 🗃️ Database Schema

**Table:** `bloodbanks`

| Column         | Type    | Description                          |
|----------------|---------|--------------------------------------|
| `id`           | INTEGER | Primary key (auto-increment)         |
| `name`         | TEXT    | Name of the blood bank               |
| `city`         | TEXT    | City where it is located             |
| `address`      | TEXT    | Street address                       |
| `phone`        | TEXT    | Contact number                       |
| `blood_groups` | TEXT    | Blood groups available               |

> ⚠️ Running `create_db.py` drops and recreates the `bloodbanks` table, so any existing data will be replaced.

---

## 🔎 How It Works

1. The user enters a city name in the search form on the home page.
2. The form is submitted via `POST` to the `/` route.
3. The app runs a parameterized SQL query:
   ```sql
   SELECT * FROM bloodbanks WHERE city LIKE ?
   ```
   with the value `%<city>%`, giving a case-insensitive partial match.
4. Matching records are passed to `index.html` and displayed to the user.

Parameterized queries are used throughout, which protects against SQL injection.

## ➕ Adding More Blood Banks

Edit the `INSERT INTO bloodbanks ...` statement in `create_db.py`, adding rows in this format:

```sql
('Blood Bank Name', 'City', 'Address', 'Phone', 'Blood groups available')
```

Then re-run:

```bash
python create_db.py
```
